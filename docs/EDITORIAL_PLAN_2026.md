# 웅비 2026 교지 기사 기획 원칙

## 기준

- 2025년 교지는 **책의 구성 방식과 연감형 흐름만 참고**한다.
- 언론자료함에는 **발행일이 2026년인 자료만** 넣는다.
- 제목에 “2026학년도”가 들어 있어도 2025년에 발행된 기사는 자료함에서 제외한다.
- 외부 기사의 문장을 교지 원고에 복사하지 않는다.
- 외부 언론사진은 원문에 사진이 있어도 사용권 확인 전에는 교지에 복사하지 않는다.
- 기존 학생 원고와 실제 작성 중인 기사는 자동으로 덮어쓰지 않는다.
- 자동 초안은 완성기사가 아니라 **취재질문 + 사실확인 자료 + 글쓰기 구조**다.

## 2026 언론자료 DB

현재 30건의 2026 자료를 연결했다.

중복 보도도 무조건 제거하지 않는다. 같은 사건에 대한 서로 다른 보도는 다음 목적으로 보존한다.

1. 날짜·인원·결과 등 사실 교차확인
2. 사진 출처 추적
3. 매체별 강조점 비교
4. 학생이 새로 확인해야 할 질문 찾기

학교 이전처럼 의견이 갈리는 주제는 기사·기고·사설·인터뷰를 구분하고, 학생 기사에서는 찬성·반대·유보 등 관련 관점을 직접 추가 취재한다.

## 학생에게 자동 생성되는 초안

완성된 기사를 자동 작성하지 않는다. 다음 요소만 제공한다.

1. 이 기사가 묻는 핵심 질문
2. 실제 취재로 채울 인터뷰 질문
3. 연결된 2026 자료 제목·날짜·매체
4. 현장 장면을 직접 적는 자리
5. 학생의 해석과 남은 질문을 적는 마무리 자리

따라서 학생은 인쇄·조판·preflight를 신경 쓰지 않고 **취재 → 글 → 사진 → 제출**에 집중할 수 있다.
