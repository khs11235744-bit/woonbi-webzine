# 웅비 v0.6 디자인 검토 50개

실제 50명을 인터뷰한 결과가 아니라, 대학신문 편집자·웹진 디자이너·학생 기자·교사·모바일 독자 5개 역할을 각 10개 관점으로 나눈 디자인 검토입니다.

1. 첫 화면의 카드 앱 느낌 축소

7. 둥근 카드 남용 제거
8. 그림자 효과 최소화
