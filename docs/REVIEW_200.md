# 웅비 웹진 — 100개 가상 검토 역할, 200가지 개선점

실제 전문가 100명에게 설문하거나 인터뷰한 결과가 아닙니다. 교지 편집 40개·웹진 30개·인터넷신문 30개 역할을 가정하고, 각 역할이 2개씩 제안한 설계 검토입니다. 역할에는 실존 인물 이름을 붙이지 않았습니다.
