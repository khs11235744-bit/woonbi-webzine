# 웅비 Anti-Slop Editorial System

웅비는 ‘현대적·깔끔한 웹사이트’가 아니라 학교가 실제로 편집한 잡지처럼 보여야 한다. 따라서 화면 구성은 범용 SaaS 컴포넌트보다 기사 중요도·사진 성격·글 장르에 먼저 반응한다.

## 금지하는 기본값
- 보라/파랑 장식 그라데이션
- 모든 요소에 같은 큰 radius와 diffuse shadow
- 같은 높이·같은 무게의 카드 3개/4개 반복
- 의미 없는 아이콘·이모지·배지
- 내용을 가리지 않는 빈 hero 문구
- 모든 카드의 hover scale/bounce
- 모든 섹션을 같은 여백·같은 구조로 반복
- bento grid를 내용과 무관하게 사용
- 큰 여백을 ‘프리미엄’ 장식처럼 사용

## 웅비의 고정 문법
- 종이색 배경, 먹색 본문, 웅비 남색, 제한된 적갈색
- 모서리는 기본 0
- 그림자는 문서 계층이 실제로 뜰 때만 사용
- 세리프는 제목/인용, 산세리프는 정보·도구
- 사진은 기사 장르에 따라 비율이 달라진다
- 중요도 차이를 크기·위치·열폭으로 드러낸다
- 같은 화면 안에서도 카드 높이를 억지로 맞추지 않는다
- 캡션·folio·rule·drop cap·pull quote 같은 출판 문법을 우선한다

## 기사별 6개 편집 처리
1. PHOTO ESSAY — 사진이 주인공. 웹은 큰 사진, 잡지는 4p 사진 특집.
2. PEOPLE — 인물 비율과 인터뷰 호흡. 잡지는 2p 인물면.
3. INQUIRY — 질문·근거·번호 체계. 잡지는 2p/4p 탐구면.
4. ESSAY — 본문 폭을 좁히고 활자를 우선. 잡지는 1p/2p 문예면.
5. FEATURE — 큰 제목과 wide image. 잡지는 4p 특집.
6. SCHOOL NEWS — 짧고 조밀한 정보 위계. 잡지는 1p 뉴스.

## 판정 원칙
기사 category, planKind, 제목·deck의 구체적 단어, 사진 수, 본문 길이를 이용해 결정한다. 동일한 기사 데이터가 웹 카드와 향후 인쇄 템플릿을 동시에 선택한다.

## 리뷰 질문
- 이 화면에서 가장 중요한 기사 하나가 1초 안에 보이는가?
- 카드의 크기 차이가 기사 중요도와 연결되는가?
- 장식 하나마다 편집적 이유가 있는가?
- 웅비 로고를 가리면 다른 학교/스타트업 사이트와 구분되는가?
- 모바일에서 비대칭을 억지로 유지하지 않고 읽기 흐름으로 환원되는가?
- 인쇄 잡지로 옮길 때 다시 디자인해야 하는가, 아니면 같은 구조가 이어지는가?

마지막 질문에 ‘다시 디자인해야 한다’면 데이터 구조부터 잘못된 것으로 본다.
