# 웅비 v0.6R · 300역할 리뷰

실제 사람 300명에게 설문한 결과가 아니라, **교지 편집자 100역할 + 개발자 200역할**로 나눠 수행한 구조화 리뷰다. 사용자에게 실제 인터뷰처럼 오해되지 않도록 역할 기반 검토임을 명시한다.
