# 운영·배포 경계

현재는 로컬 편집 파일럿입니다. Google OAuth, 여러 실제 학생 계정, Firestore/Storage 규칙과 학교망을 검증하기 전에는 실운영 완성으로 보고하지 않습니다.

## 자료
학생 이름·계정, 원고, .woongbi 백업, 교지 PDF와 학교 사진은 GitHub 코드에 넣지 않습니다. 실제 자료가 들어간 HTML도 공유 범위를 제한합니다. 웹용 사본과 인쇄 원본은 따로 보관합니다.

## 사진
교체용 사진은 초안 배치를 보는 용도입니다. 실제 기사 현장으로 해석하지 않도록 표시하고, 제출·발행·책 확정 전에 바꾸거나 제거합니다. 학교의 초상·인터뷰·사진 공개 기준을 별도로 확인합니다.

## 계정
교사 권한은 신뢰 가능한 서버 관리 경로로만 최초 부여합니다. 로그인 성공과 기자 승인은 다릅니다. 공용 PC에서는 원고 사본을 안전한 곳에 보관한 후 로그아웃합니다. 로컬 브라우저 체험의 역할 선택은 보안 경계가 아닙니다.

## 출판
웹 승인과 책 수록 동의를 나눕니다. 책 확정본은 이후 수정과 분리합니다. A4 검토본은 PDF/X 인증·정밀 자동조판을 뜻하지 않습니다. 최종 교정과 인쇄소 검수는 별도입니다.

## 배포
별도 woonbi- Firebase 프로젝트만 사용합니다. INDI+P나 다른 프로젝트를 대상으로 배포하지 않습니다. Firebase 실제 배포 명령은 CI에 넣지 않았습니다. Storage 이용 요금·보존 정책은 소유자가 검토한 뒤 설정합니다.

## 검토 방법
200개 항목은 실제 전문가 100명의 설문이 아닌 100개 가상 역할의 설계 검토입니다. 로컬 형식 검사 통과는 사실 검증·전체 접근성 인증·학생 실계정 보안을 보증하지 않습니다.
