# 웅비 — 오늘의 포항고 / 학교 정보 연동 100개 검토안

2026-09-23. 상태: 출처 조사·설계. 구현·실서비스 검증·배포 완료를 뜻하지 않습니다.

실제 100명을 인터뷰한 결과가 아닙니다. 재학생, 급식·보건 담당, 학사일정 이용자, 학교 소식 담당, 웹진 편집자, 학생 기자, 학부모·독자, 개인정보·보안 담당, 개발자, 운영·출판 담당을 각각 10개 가상 역할로 나눈 검토입니다. 투표 수나 실제 선호 통계가 아닙니다. 기존 REVIEW_200.md의 구현 완료 수에 합산하지 않습니다.

## 설계 방향

학생 기사가 중심이고 생활정보는 작은 ‘오늘의 포항고’로 둡니다. 학교 홈페이지 전체를 복제하지 않습니다. 급식을 확인하러 왔다가 학생 기사를 읽고, 학교 공지가 학생의 취재거리로 이어지는 구조를 제안합니다.

머리글 → 오늘의 포항고(급식/이번 주 일정/주요 공지) → 학생 대표 기사 → 학교생활·인터뷰·탐구 → 사진 기록·지난 호. 모바일 생활정보는 접기·펼치기를 지원하고 큰 자동 슬라이드는 넣지 않습니다.

## 확인된 출처와 미검증 사항

- 포항고 공식 홈페이지에 공지사항, 학교일정, 가정통신문, 금주식단, 오늘의 식단, 보도자료 메뉴가 있습니다.
- NEIS 공식 급식식단정보는 일자별 메뉴·원산지·칼로리·영양 정보와 알레르기 번호를 제공합니다. 공식 적재 주기는 매일입니다.
- NEIS 학사일정은 행사명·날짜·내용·학년별 행사 여부를 제공합니다.
- 공지사항과 보도자료 목록에 RSS 표시가 있으나 실제 피드 URL과 XML 응답을 검증하지 못했습니다. RSS가 작동한다고 확정하거나 피드 URL을 추측하지 않습니다.
- 키 없는 NEIS 샘플은 5건 제한입니다. 운영은 발급받은 키로 페이지 전체를 검증해야 합니다. API 무료와 호스팅·저장·알림 비용 무료는 별개입니다.
- 현재 실행 환경의 직접 HTTP 요청은 NEIS와 학교 호스트의 DNS 해석에 실패했습니다. 학교나 NEIS 장애로 확정하지 않습니다. 오늘 식단과 최신 공지의 실응답 검증은 대기입니다. 검색·웹 수집 화면에 보이는 오래된 식단을 오늘 정보로 게시하지 않습니다.

P0: 정확한 학교 식별, 오늘 중식·석식, 메뉴·원본 알레르기 정보, 날짜와 마지막 정상 확인 시각, 실패·미등록 구분, 주요 공지 원문 연결, 공개·비공개 경계, 제한 재시도와 장애 격리.

P1: 이번 주 일정, 교사 중요 공지 선택, 수동 갱신, 수정 이력, 공지를 취재거리로 저장하고 배정, 운영 상태판.

P2: ICS, 날짜별 공유 카드, 추가 개인화. 급식 투표·건강 프로필·학생 전체 사진 자동 복사는 초기 범위에서 제외한다.

모든 단계에서 학교 정보는 서버가 수집하고 검증된 공개 필드만 캐시로 내려준다. 원문 게시일·수정일, 마지막 시도, 마지막 성공, 적용일을 각각 관리한다. 교사 임시 변경은 근거·확인자·적용 시작/종료를 기록한다.
